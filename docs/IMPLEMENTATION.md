# 관전 시뮬레이터 첫 구현

날짜: 2026-10-20. 엔진 `dnf-core-sim-0.1`, 봇 `baseline-0.1`.

## 현재 구현

React·TypeScript, Sites가 제공한 Vinext/Vite starter를 `web/`에 설치했다. UI와 독립적인 엔진, 데이터·봇·Worker를 분리했다. 세 리더와 기본 스킬 포함 전체 61종을 구조화했다. 각 플레이덱은 공용 동료 포함 동료 22장, 전용 스킬 14장, 공용/전용 이벤트 14장으로 50장이다. 카드별 최대 4장과 속성을 검증한다.

기본 봇은 저비용 동료가 없으면 시작 손패 전체를 한 번 교체한다. 파밍·공격·방어·소환·등록·이벤트·레벨업을 평가한다. 합법 행동 검증과 실제 판정은 엔진에서 수행한다. 파티 후보는 단독·둘·전체를 중심으로 제한하며, 엔진은 별도로 주어진 합법 파티와 지불 방법을 검사할 수 있다.

손실 대상이나 탐색 대상이 명시되지 않으면 엔진의 결정적인 기본 선택을 사용한다. 이는 첫 버전의 봇 정책이며 사용자의 수동 선택을 기다리는 단계가 아니다. 관전 로그는 관측된 행동과 계산을 표시하며 생성형 해설을 지어내지 않는다.

관전 화면, 실행 구간 되감기와 재생, 리더·시드 설정, JSON 내보내기, 카드 도감, Worker 반복 실험을 연결했다. 기본 화면은 덱 순서와 히트 내용을 숨기고 손패만 양쪽 공개한다. 새로고침하면 실행 중 기록은 초기화된다.

## 검증

- 규칙·경계 조건·정보 분리·재현·카드 보존 자동 테스트 20개 통과.
- 별도 90판 종료 및 카드 총수 보존 확인. 해당 표본은 모두 5히트 종료이며 밸런스 평가 자료로 사용하지 않는다.
- 타입 검사와 Vinext 프로덕션 빌드 통과.
- 로컬 HTTP 200 확인. 실제 브라우저에서 한 행동 진행, 자동 진행, 일시정지 상태 고정 확인.
- 브라우저의 20판 Worker 실험: A 풍진 7승, B 카잔 13승, 평균 11.6턴. 5히트 19판, 몬스터덱 소진 1판. 이 결과는 첫 실행 검증이다.
- 390px 화면에서 가로 넘침 없음 확인. 모바일에서는 세로 스크롤을 사용한다.
- 1440px에서 양쪽 손패를 전장 상단에 나란히 배치한 수정본을 확인했다. 최초 상하 배치에서는 하단 손패가 화면 밖으로 밀렸다.
- Worker의 최초 URL 변환 오류를 실제 브라우저에서 발견해 Vite `?worker` 가져오기로 수정했다.
- 비공개 Sites 배포 성공 후 실제 배포 주소에서도 한 행동 진행과 동일한 20판 Worker 실험 결과를 확인했다.

## 환경 기록

Windows에서 Sites 설치·빌드 helper의 패키지 매니저 shim 호출이 실패했다. 같은 starter의 pnpm 직접 설치와 `node scripts/run-framework.mjs build`로 수행했다. 패키지 설치와 로컬 런타임 시작에는 샌드박스 밖의 링크/루프백 권한이 필요했다. pnpm native build 허용은 프로젝트 `pnpm-workspace.yaml`에 esbuild·sharp·unrs-resolver·workerd만 기록했다.

## 남은 작업

실제 던파 카드 아트 매핑, 봇의 성장·자원 보존 개선, 파티 후보 확대, 덱 편집, 저장/불러오기, 장시간 실험 성능 개선. 실제 카드 아트는 이번 배포 파일에 포함하지 않는다. 모든 카드 조합의 판정이 검증됐다고 주장하지 않는다.

## 튜토리얼 개선 (2026-10-22)

로드맵 `TUTORIAL_ROADMAP.md`의 1–4단계를 구현했다. 봇 `baseline-0.2-explained`는 같은 점수 함수에서 추천과 후보 순위를 반환한다. 기존 코어의 점수 정책을 유지하며 재건 프로필에만 재건 후보를 추가했다. 해설은 관측 가능한 상태와 실제 전이로 계산한다. 동점이면 후보 생성 순서로 고른다고 표시한다. 최적 수·장기 승률·생성형 추측을 표시하지 않는다.

기본 진입은 7장면 학습 모드다. 소환·사냥·성장·파티 공격·방어·정예 보상·재건을 고정 배치에서 실행한다. 말풍선에 행동 주체·이유·기회비용·전후 경험치/손패/동료/파워를 표시한다. 핵심 선택 뒤 자동 정지를 기본으로 제공하고 한 행동 진행·되감기·장면 재시작을 유지했다. 파티와 방어 장면은 결투 결과까지 확인해야 학습 완료로 표시한다.

우측 대안 비교는 같은 행동 직전의 합법 후보 4개와 단계 종료를 보여준다. 미리보기는 원본 상태를 수정하지 않는다. 분기는 해당 시점 뒤 기록을 교체하며 원래 고정 배치 또는 자유 관전의 시드 초기화로 복원한다. 내보내기에 규칙 프로필·봇 버전·장면 ID·장면 버전 `lessons-0.1`을 포함한다. 기록 불러오기와 영구 저장은 아직 없다.

실험 `dnf-lab-0.1`은 원본 코어와 분리했다. 정예 구성/400 이상 토벌 추가 드로우, 조건부 게임당 1회 레스트 재건, 결합 프로필을 제공한다. Worker는 원본과 선택 프로필을 같은 시드·선후공 교대로 규칙당 20/100/500판 실행한다. 판당 사냥·정예 보상·재건 횟수와 종료 원인을 기록한다. 정예 던전은 구성과 보상을 함께 바꾸므로 단독 효과를 추론하지 않는다.

검증: 기존 20개와 추가 11개 자동 테스트 통과. 장면 카드 보존·재현·실제 추천·방어 주체·숨은 정보·대안 불변성과 분기·정예 성공/동률/실패/덱 소진·재건 조건/1회/탐색 우선/셔플·짝 조건 집계를 포함한다. 네 프로필에서 카잔/케이트 시드 789 대전을 끝까지 실행하면서 매 행동 카드 보존과 해설 생성을 추가 확인했다. 타입 검사와 프로덕션 빌드도 수행했다.

브라우저 검증: 핵심 행동 뒤 자동 정지, 시즈키 소환으로 대안 분기, 방어 파워 500→900과 공격 900 동률 처리, Enter 키 한 행동 진행, 재건 레스트 소환, 장면 이동을 확인했다. 1440px·1024px·390px에서 가로 넘침이 없고 390px에서 단일 열 배치가 적용됨을 확인했다. 원본/결합 각 20판 Worker 결과는 원본 A 7승/B 13승 평균 11.6턴, 결합 A 7승/B 13승 평균 11.4턴이었다. 결합은 판당 정예 보상 1.05회, 재건 0회였다. 500판 실행 취소와 버튼 재활성화, 콘솔 오류 없음도 확인했다. 이 표본은 기능 검증이며 재미·밸런스·상업성의 증거가 아니다.

5단계 사람 이해도·재대전·상품 효용 검증과 콘텐츠/실제 아트 확장은 후속 작업이다.

## 2026-11-19 사냥 사이드뷰

첫 진입점은 기존 코어 사냥 학습 배치다. 실제 후보 순위와 선택, 행동 전후 스냅샷으로 선언·충돌·휴식·손실·파밍존 이동을 재생한다. 배치나 규칙 버전 변경은 없다. 픽셀 숲과 캐릭터는 Canvas 2D로 직접 그린다. 재생 중 정지·속도·시점 이동, 즉시 결과, 대안 선택, 카드·진영·판정 상세와 기존 분석 화면으로 이어보기를 제공한다. 큰 화면의 분석 항목은 전장·해설·기록과 대안으로 전환하며 도감은 페이지를 넘긴다.

규칙·튜토리얼 테스트 31개와 타입 검사, 프로덕션 빌드 통과. 설치된 Chrome에서 1920×920, 1920×880, 1536×700, 1280×600의 콘텐츠 영역을 사용해 시작·종료·기록·되감기의 가로·세로 넘침과 조작 위치를 검사했다. 1920×900에서 카드 상세 키보드 조회와 대안 분기, 분석 전장·해설·기록·도감·실험 메뉴를 확인했다. 390px에서는 가로 넘침과 모션 축소 즉시 결과를 확인했다. 디스플레이 크기 대신 탭·주소창·북마크바·작업표시줄을 제외한 페이지 영역을 검사한 결과다. 반복 검사 파일은 web/tests/hunt-layout.qa.cjs다.

## 2026-11-19 직접 대전과 세로 전장

플레이어(A)와 기본 봇(B)이 표준 코어 덱을 사용한다. 리더와 시작 손패 유지/전체 교체를 고른 뒤 행동 주체 기준으로 입력을 받는다. 결투 중 상대 턴에도 방어 파티·스킬·이벤트를 선택하며 파티와 지불 자원은 직접 조정할 수 있다. 확정 행동은 기존 검증과 상태 전이를 거친다. 판정 중 파티 손실·대체 대상과 효과 탐색을 생략하면 기존 엔진의 기본 선택을 적용한다. 튜토리얼 전환 중에는 대전 진행이 멈추며 복귀해 이어갈 수 있다. 대전은 현재 탭의 메모리에 유지한다.

대전 전장은 384×176, 튜토리얼은 576×176 내부 해상도를 가로세로 같은 배율로 확대한다. 세로 화면은 전장과 조작부를 위아래로 둔다. 배경의 숲 경계를 올리고 흙길이 앞쪽으로 넓어지도록 그려 뒤쪽 몬스터 발밑에도 바닥이 보인다. 카메라를 기울이거나 캐릭터를 변형하는 방식은 사용하지 않았다.

기존 규칙과 시작 패 회귀 테스트를 포함해 32개 통과. 타입 검사 및 프로덕션 빌드 통과. 크롬 자동 입력으로 직접 대전 18턴, 플레이어 결정 52회, 소환·이동·사냥·결투·상대 턴 방어를 거쳐 5히트 패배와 재대전 진입을 확인했다. 시작 패 교체 결과는 별도 브라우저 기록에서 확인했다. 360·390·430px 세로 화면에서 가로 넘침과 두 모드의 픽셀 비율을 검사했고 1920×880에서 대전 주요 화면의 세로 넘침도 검사했다. 실제 휴대폰 기기 검증은 별도다.

## 2026-11-19 상대 대사와 직접 대전 속도

상대가 확정한 행동으로 전장 오른쪽 리더 위에 평어체 말풍선을 표시한다. 행동 전의 실제 주체로 방어 반응을 구분하고, 사용한 카드와 공개한 대상, 드로우 장수만 대사에 활용한다. 기본 ‘한 수씩’은 다음 자동 행동 전에 판정·주요 행동을 읽도록 대기한다. 플레이어의 선택 차례에는 바로 입력할 수 있다. ‘천천히 자동’은 주요 행동에 최소 3.2초를 주며 ‘빠르게 자동’도 선택할 수 있다.

규칙·대사 테스트 34개, 타입 검사 및 프로덕션 빌드를 통과했다. 로컬 크롬에서 390px 세로 화면 말풍선, 수동 대기와 다음 행동, 느린 자동 판정, 빠른 자동 전환을 확인했다. 1920×880 대전 화면에서 표시 영역을 확인했고, 직접 입력 52번으로 18턴 5히트 종료와 재대전까지 실행했다.

## 2026-11-19 초보자 판정 도움말

직접 대전에서 각 행동 전후 상태를 비교해 짧은 원인·결과 설명을 행동 선택 위에 표시한다. 결투의 선언·방어 지원·강화·최종 판정을 구분하며, 실제 히트 수 변화·대상·대체 손실·덱 부족·동료 손실을 반영한다. 사냥, 이동, 소환과 지불, 스킬 등록, 레벨업, 운영 이벤트, 턴 진행에도 해당 행동의 해설을 붙였다. 주요 유형을 처음 만났을 때 팝업이 자동 진행을 멈춘다. 자동 팝업을 꺼도 해설은 남고, ‘방금 판정’ 또는 ‘대전 기록’에서 당시의 설명을 다시 읽을 수 있다. 계산 내역은 팝업에서 펼친다.

테스트 37개, 타입 검사, 프로덕션 빌드 통과. 로컬 크롬에서 풍진 공격 500과 카잔 방어 500의 동점, 받은 히트 0 → 0을 직접 재현했다. 세로 화면에서 팝업 열기·닫기, 자동 진행 일시정지, 팝업 끄기 및 이전 판정 다시 보기를 확인했고, 18턴 52개 플레이어 결정 후 5히트 종료까지 진행했다.

## 2026-11-19 손패 선택 미리보기

손패에서 사용·등록 가능한 카드를 표시하고, 사용할 수 없는 카드도 눌러 단계, 리더 레벨, 경험치 부족량과 대상 조건을 확인할 수 있다. 선택한 소환·등록·이벤트·강화·사냥·결투는 확정 전 규칙 엔진으로 미리 계산한다. 실제 대전 기록에는 확정한 행동만 남는다. ‘재정비’는 지정한 몬스터를 남겨 두는 지불 방법도 선택할 수 있다.
