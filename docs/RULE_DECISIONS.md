# 시뮬레이터 판정 결정표

규칙 버전: `dnf-core-sim-0.1`  
상태: 사용자 승인, 첫 엔진 반영 및 관련 경계 조건 테스트 완료(상세 검증 범위는 IMPLEMENTATION.md)  
승인일: 2026-10-20  
근거: 사용자가 이전 대화의 권장안 전체를 채택. 원본 룰북의 미정·충돌 부분에 한해 아래 판정을 적용한다.

| ID | 확정 판정 | 필수 검증 |
|---|---|---|
| R01 | 결투당 진영별 스킬 최대 1개. 기본 스킬 포함. 스킬 사용은 선택 사항이며 전투 이벤트는 별도로 진영별 최대 1장이다. | 기본 스킬 반복·복수 스킬 차단, 스킬+이벤트 허용 |
| R02 | 레스트된 리더·동료도 공격 대상이 될 수 있고 본인의 파워·능력·방어 스킬을 적용한다. 다른 레스트 동료는 방어 파티에 참여할 수 없다. | 레스트 대상 방어 허용, 레스트 지원자 차단 |
| R03 | 공격 파티의 참여 상한은 선언 시점의 개인 파워로 비교한다. 레벨·지속·공격 시 개인 효과를 포함하되 스킬·이벤트·파티 구성으로 생기는 보정은 제외한다. 편성 이후 재구성하지 않는다. | 동일 파워 허용, 더 강한 동료 거부, 풍진 파티 보정으로 소급 재편성 금지 |
| R04 | 공격 파티는 공격자와 같은 존의 활성 동료만 참여한다. | 존 간 지원·레스트 지원 차단 |
| R05 | 스킬 사용자와 스킬의 속성이 하나 이상 일치해야 한다. 공용 스킬은 모두 사용할 수 있다. 사용 레벨은 사용자가 동료여도 리더 레벨로 판단한다. | 공용 동료의 전용 스킬 사용 불가, 기본 스킬 허용, 리더 레벨 적용 |
| R06 | 파밍 경험치는 비용 지불에 필요한 만큼 생산하고 즉시 소비한다. 선생산·잔액 저장을 하지 않는다. 카잔 Lv2 능력으로 얻은 경험치만 해당 자기 턴 종료까지 보관한다. | 활성→레스트→디스카드, 이중 소비 방지, 카잔 잔액 만료 |
| R07 | 히트에 옮길 카드가 덱에 없으면 즉시 패배한다. | 빈 덱 히트, 마지막 카드 히트 후 다음 드로우 |
| R08 | 동료가 파괴되면 부착된 레벨업 몬스터도 소유자의 디스카드존으로 이동한다. | 부착 효과 제거, 카드 총수 보존 |
| R09 | EV9는 일반 일회용 이벤트다. `[1회성]`을 별도 게임당 제한으로 사용하지 않는다. 다른 EV9를 사용하면 다시 효과를 처리한다. | 복수 EV9 사용, 디스카드 우선 탐색, 대상 없음 |
| R10 | 턴 종료에는 턴 플레이어가 레벨업 대상을 하나씩 선택한다. 각 레벨업의 발동 효과를 마친 후 다음 대상을 처리한다. 각 대상은 턴당 최대 1레벨. 마지막에 몬스터덱 소진 종료를 판정한다. | 케이트 Lv2 효과 즉시 처리, 중복 레벨업 금지, 종료 시 최종 레벨 반영 |

## 문서 정정과 후속 확인
- 원본은 직접 수정하지 않는다. 파워가 모두 100 단위라는 설명과 +50 몬스터 효과의 충돌은 카드별 명시 수치(+50)를 보존하는 방향으로 처리한다.
- 목차의 부록 B·C는 현재 추출 본문에서 확인되지 않았다. 존재하지 않는 테스트·확정 이력을 가정하지 않는다.
- 이 표의 R03은 파티 편성 자격 비교용이다. 실제 결투 총파워와 손실 판정의 개인 파워는 원본 및 관련 효과를 별도로 해석한다.
- 추가 공백은 발견 시 근거·영향·제안·승인 상태를 기록한다. 아직 구현하지 않은 판정을 구현 완료로 표시하지 않는다.
