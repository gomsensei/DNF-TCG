# 튜토리얼 시뮬레이터 개선 로드맵

2026-10-22 사용자 요청에 따른 구현 계획이다. 기존 코어 규칙을 대조군으로 유지하고 개선 규칙은 이름과 버전이 있는 실험 프로필로 분리한다. 사람이 게임의 흐름과 선택의 득실을 이해하는 것이 우선 목표다.

| 단계 | 구현 결과 | 완료 기준 |
|---|---|---|
| 1 선택 해설 | 봇 점수 평가와 같은 경로에서 근거를 기록하고, 행동 주체의 말풍선에 이유·대가·전후 변화를 표시 | 모든 행동에 설명, 숨은 정보 비노출, 재생/되감기와 설명 일치 |
| 2 장면별 학습 | 소환·사냥·성장·파티 공격·방어·보스·재건 예제, 목표 안내, 핵심 행동 뒤 자동 정지 | 원본 엔진으로 실행되는 장면, 카드 보존, 장면 선택 시 설정 일치 |
| 3 선택 비교 | 같은 행동 직전 상태에서 추천과 합법적인 대안을 비교하고 분기 실행 | 설명상 차이와 실제 상태 차이 일치, 분기 시 이후 기록 교체, 원래 경로 재현 |
| 4 개선 실험 | 정예 던전/보상, 조건부 1회 재건, 원본 대조 Worker 실험 | 프로필별 리플레이, 짝 시드·선후공 교대, 결과의 규칙·봇·표본 기록 |
| 5 사람 검증과 콘텐츠 | 사람 관전 이해도·재대전 의향·던전/개인덱 구매 효용을 검증하고 역할 카드·아트 확장 | 실제 사용자 관찰과 비용 자료 확보 후 별도 콘텐츠 설계 |

## 해설 원칙

말풍선은 생성형 이야기 대신 실제 선택 점수와 관측 가능한 상태에 근거한다. 봇의 판단은 '봇 판단', 비용·레스트·카드 수 변화는 '실제 결과'로 구분한다. 전투 선택 시 상대 손패를 보았다고 말하지 않는다. 추천은 제한된 후보의 휴리스틱 선택이며 최적 수나 승률로 표현하지 않는다.

튜토리얼은 학습을 위한 고정 배치다. 무작위 대전의 일반적 결과와 구분하고, 선택한 행동은 같은 엔진으로 검증·적용한다. 대안의 즉시 결과만 비교하고 장기 승률을 만들어내지 않는다.

## 실험 규칙 설계

- 코어: 승인된 `dnf-core-sim-0.1`.
- 정예 던전: 50장 구성 `[6,6,6,8,8,6,4,2,2,1,1]`. 파워 400 이상 몬스터 사냥 성공 시 드로우 1장 추가. 기존 사냥 손실과 레벨업 효과는 유지한다. 별도 전역 효과는 추가하지 않는다.
- 재건 지원: 각 플레이어 게임당 1회, 자기 운영 단계에 동료가 없고 가용 경험치가 0일 때 사용 가능. 자기 디스카드, 없으면 덱에서 견습 모험가 1장을 찾아 비용 없이 레스트 소환한다. 덱을 찾으면 셔플한다. 대상이 없으면 사용 불가. 다음 자기 턴부터 사냥에 복귀할 수 있으며 패배를 취소하지 않는다.
- 결합: 두 개선을 함께 적용. 단독 프로필과 분리해 원인을 비교한다.

이 수치와 효과는 테스트용이며 상용 카드나 최종 밸런스 확정이 아니다. 정예 던전은 구성과 보상을 함께 바꾸므로 결과 차이를 어느 하나의 단독 효과로 해석하지 않는다. 새 직업·역할 카드, 상품 판매·결제·예약 구매는 이번 구현에 포함하지 않는다.

## 검증

기존 경계 조건 테스트를 유지한다. 선택 점수와 해설 연결, 관측 정보 분리, 시점별 설명, 튜토리얼 카드 보존, 대안 분기·재현, 재건의 조건·횟수·탐색, 정예 보상의 성공 조건, 실험 프로필 기록을 검증한다. UI에서는 자동 정지·계속 재생·장면 이동·말풍선·좁은 화면·Worker 취소를 확인한다. 단계별 실제 완료 상태는 IMPLEMENTATION.md에 기록한다.

## 구현 상태 (2026-10-22)

1–4단계를 사용 가능한 프로토타입으로 구현했다. 7개 장면은 모두 같은 규칙 엔진의 합법 행동을 적용한다. 파티와 방어는 선언만 보고 완료하지 않고 결투 결과를 확인한 뒤 다음 장면으로 넘어간다. 말풍선은 실제 행동 직전의 관측 정보로 평가하며, 되감기와 대안 분기에 따라 함께 갱신된다. 첫 행동 전에는 ‘다음 봇 선택 미리보기’로 구분한다.

5단계는 사람 검증이 필요하다. 다음에는 규칙을 읽지 않은 사람이 관전 후 ‘사냥에 몇 명을 보낼지’, ‘어떤 비용을 남길지’를 설명할 수 있는지, 다른 던전을 다시 해보고 싶은지 측정한다. 던전 공유 구매와 개인 덱·외형 수집의 효용을 별도로 물어보고 가격과 제작 비용을 확보한 뒤 상품 구성을 결정한다. 현재 반복 대전 통계만으로 재미나 매출 개선이 입증되었다고 보지 않는다.
