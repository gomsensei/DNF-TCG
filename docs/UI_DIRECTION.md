# 기본 UI와 이미지 방향

## 확정 방향 관전형 전장
2026-10-20 사용자 지시: 실제 플레이보다 자동 시뮬레이션을 관전하는 방향. 양쪽 손패를 동시에 보여준다. 앞서 선택한 단계 안내형의 설명을 유지하되 직접 조작 대신 현재 행동을 안내한다.
- 전장 최상단: A/B 앞면 손패를 나란히 모아 관전 중 동시에 비교한다. 첫 구현의 브라우저 검사에서 상하 손패가 한 화면에 들어오지 않아 조정했다. 작은 화면에서는 A/B 손패 영역을 세로로 이어서 표시한다.
- 상단 전장: B 리더·레벨·받은 히트 수, 결투장·던전 동료·파밍·스킬.
- 중앙: 공용 던전 몬스터 4장, 현재 턴·단계와 진행 중인 행동.
- 하단: A의 전장·자원·스킬. 모든 카드는 관전자 방향으로 읽게 배치한다. 장수 증가 시 상단 손패는 줄바꿈한다.
- 우측: 현재 행동 주체와 대상, 실제 판정의 계산 근거, 선택 카드 상세와 로그. 봇 선택 이유는 정책이 기록한 근거만 표시하고 해설을 지어내지 않는다.
- 상단 조작: 자동 진행/일시정지, 한 행동 진행, 속도. 실행 전 리더·덱·봇·시드 선택. 수동 공격·방어·비용 선택은 핵심 UX가 아니다.
- 관전자에게 양쪽 손패를 공개해도 봇은 자기 손패와 공개 정보만 받는다. 덱 순서와 비공개 히트 내용은 기본 화면에서 숨긴다. 관전자 표시 변경은 원본 게임 규칙 변경이 아니다.
- 드로우·사용·파괴·레벨업에 해당 카드를 강조한다. 받은 히트는 `받은 히트 2/5`로 표시한다. 레스트는 회전뿐 아니라 텍스트로도 표시한다.
- 데스크톱에서는 양쪽 손패를 동시에 배치하고 좁은 화면에서는 양쪽을 세로로 이어서 보여준다. 무제한 손패에서 모든 카드를 화면 한 장에 축소해 넣으려 하지 않는다.

## 시안 상태
이전 시안은 초기 탐색안으로 남긴다. 현재 `web/`의 구현 화면에는 실제 엔진·기본 봇·Worker 통계를 연결했다. 실제 카드 아트는 미수록이며 텍스트와 유형별 프레임을 사용한다. 구현·검증 범위는 `IMPLEMENTATION.md`를 확인한다.

## 던파 이미지 조사
- 한국 공식 월페이퍼: https://df.nexon.com/pr/dfonwallpaper
- 글로벌 공식 미디어: https://www.dfoneople.com/media/wallpaper
- 리더/NPC, 몬스터, 스킬 아이콘 순서로 카드별 정확한 대응 자료를 조사한다. 풍진·케이트·카잔에 맞지 않는 이미지를 정확한 인물로 표시하지 않는다.
- 현재 두 공식 출처의 존재를 웹 검색으로 확인했으며 개별 이미지의 이용 조건·카드 매핑·다운로드는 아직 수행하지 않았다.
- 확보한 아트는 로컬 자산으로 관리하며 카드 텍스트는 HTML로 별도 표시한다. 외부 이미지 URL에만 의존하지 않는다. 실패 시 텍스트 카드로 대체한다.
- 각 자산의 출처와 가공·이용 조건 확인 상태를 기록한다. 공식 페이지에 게시됐다는 사실을 재배포 허가로 간주하지 않는다. 공개 배포 전 확인되지 않은 자산을 교체할 수 있게 한다.
